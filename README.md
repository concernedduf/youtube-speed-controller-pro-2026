## FAQ

**Does pitch correction work at 2× and above?**  
Yes — the pitch algorithm adjusts up to 4× cleanly. Above 4× you may notice artifacts.

**Can I set different speeds for music vs lectures?**  
Yes — enable per-channel memory and each channel remembers its last speed.
